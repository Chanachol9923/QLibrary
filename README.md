# QLibrary

คลังทบทวนบทเรียนส่วนตัว — เว็บแอปแบบ static ไม่มี build ไม่มี dependency ไม่ต้องต่อเน็ต
เปิดไฟล์ `index.html` ตรง ๆ ก็ใช้ได้ หรือจะเสิร์ฟผ่าน server ก็ได้

ความคืบหน้าทั้งหมดถูกเก็บไว้ใน `localStorage` ของ browser เครื่องนั้น (ไม่มีบัญชี ไม่มี server)

## หมวด → วิชา → บทเรียน

หน้าแรกมีตัวกรอง 2 ชั้น

1. **หมวด** (`category`) — ชั้นบนสุด เช่น `TestMidterm` · ตอนนี้ทุกวิชาอยู่ในหมวดนี้
2. **วิชา** (`subject`) — เช่น `CS461 Deep Learning`, `ภาษาญี่ปุ่น N5`

ทั้งสองชั้นมาจาก field ของ content pack โดยตรง pack ไหนตั้งค่าเหมือนกันก็ถูกจัดกลุ่มเข้าด้วยกันเอง
**ไม่ต้องไปแก้โค้ดหน้าแรก** · สิ่งที่เลือกไว้ถูกจำไว้ในเครื่อง ครั้งหน้าเปิดมาอยู่ที่เดิม

พอเทอมหน้ามีสอบปลายภาค ก็แค่ตั้ง `category: 'TestFinal'` ในไฟล์เนื้อหาใหม่ แถบหมวดจะขึ้นเองอีกอัน

## กระดาษทดสำหรับเขียนด้วยปากกา

โหมด **แสดงวิธีทำ** มีกระดาษทดในตัว รองรับ **Apple Pencil / สไตลัส / เมาส์ / นิ้ว** ผ่าน Pointer Events

- ปากกาที่ส่งแรงกดมา เส้นจะ**หนา-บางตามน้ำหนักมือ**
- **Palm rejection** — พอเริ่มเขียนด้วยปากกาแล้ว ระบบตัด input จากนิ้วทิ้ง วางมือบนจอ iPad ได้เลย
- ยางลบ**ลบจริง** (destination-out) ธีมมืดไม่เพี้ยน · มีปุ่มย้อน · กด **＋ เพิ่มพื้นที่** ต่อกระดาษได้ถ้าเขียนไม่พอ
- สีหมึกตามธีม สลับสว่าง/มืดแล้วลายมือยังอยู่
- ลายมือเก็บไว้**ในหน่วยความจำของรอบนั้น** สลับไป-กลับระหว่างข้อได้ไม่หาย แต่**รีเฟรชแล้วหาย** (ไม่ลง localStorage เพราะรูปกินพื้นที่)

ระบบไม่ตรวจลายมือให้ — กด "ดูเฉลยทีละขั้น" แล้วเทียบเอง จากนั้นกดให้คะแนนตัวเอง 3 ระดับ เข้าระบบ Leitner ตามปกติ

### ระบบจำ (Leitner)

ทุกครั้งที่ตอบ ระบบจะขยับรายการนั้นขึ้น-ลงใน "กล่อง" 1-5
กล่องยิ่งสูง ยิ่งเว้นระยะทบทวนนาน (1, 2, 4, 8, 16 วัน)
ตอบผิดเมื่อไหร่ ตกกลับกล่อง 1 ทันที

เวลาเข้าโหมดใหม่ ระบบจะเรียงให้ **ตัวที่ยังไม่เคยเจอ → ตัวที่ยังไม่แม่น → ตัวที่ถึงกำหนดทบทวน** ขึ้นมาก่อนเสมอ

### คีย์ลัด

| ปุ่ม | ทำอะไร |
|---|---|
| `Space` / `Enter` | พลิกการ์ด |
| `1` `2` `3` | ยังไม่ได้ / ไม่แน่ใจ / จำได้ |
| `1` - `4` | เลือกคำตอบในโหมดควิซ |
| `Enter` | ไปข้อถัดไปหลังเฉลย |
| `Ctrl + Enter` | ตรวจคำตอบในโหมดทดสอบเขียน |

1. copy `content/_template.js` → ตั้งชื่อใหม่ เช่น `content/cs319-w3-css.js`
2. แก้ `id`, `title` และเนื้อหาข้างใน
3. เพิ่มบรรทัดนี้ใน `index.html` (ในกลุ่มคอมเมนต์ "เนื้อหา")

```html

```

4. รีเฟรช — การ์ดบทเรียนใหม่จะขึ้นบนหน้าแรกเอง ไม่ต้องแก้โค้ดส่วนอื่นเลย

ทุก section (`topics` / `cards` / `quiz` / `write` / `work`) เป็น optional
โหมดไหนไม่มีข้อมูล ระบบจะซ่อนโหมดนั้นให้อัตโนมัติ

### วิชาภาษา vs วิชาโค้ด

ตั้ง `answerStyle` ใน pack เพื่อบอกระบบว่าจะตรวจคำตอบยังไง

| ค่า | ใช้กับ | การตรวจ |
|---|---|---|
| `'code'` (ค่าเริ่มต้น) | วิชาโปรแกรมมิ่ง | ไม่สนตัวพิมพ์เล็กใหญ่ ยุบช่องว่างซ้ำ มอง `'` เท่ากับ `"` |
| `'text'` | วิชาภาษา เช่น ญี่ปุ่น | ตัดช่องว่างทุกชนิดทิ้ง (รวม　เต็มความกว้าง) ตัด 。、ท้ายประโยค แปลงอักษรเต็มความกว้างเป็นครึ่งความกว้าง |

pack ที่เป็น `'text'` จะเปลี่ยนการแสดงผลให้ใช้ฟอนต์ปกติตัวโตแทนฟอนต์โค้ดด้วย
และในโหมดทดสอบเขียน ช่องว่าง `（　）` ในโจทย์จะถูกไฮไลต์ให้เห็นชัด

### คำอ่านโรมาจิ

บรรทัดที่เป็นภาษาญี่ปุ่นล้วนจะมี **คำอ่านโรมาจิตัวเล็ก ๆ กำกับใต้บรรทัด** ให้อัตโนมัติ
ทุกโหมด — การ์ด โจทย์ ตัวเลือกควิซ เฉลย ตัวอย่างประโยค และช่องในตาราง
ไม่ต้องพิมพ์คำอ่านเองในไฟล์เนื้อหา

ตัวแปลงเป็นแบบเฮ็ปเบิร์น และดูแลจุดที่มักอ่านผิดให้ด้วย

| กรณี | ผลลัพธ์ |
|---|---|
| คำช่วย `は` | อ่าน **wa** ไม่ใช่ ha (`わたしは がくせいです。` → `watashi wa gakusei desu.`) |
| `っ` | ซ้ำพยัญชนะ (`ざっし` → `zasshi`) |
| `ー` | ยืดสระ (`コンピューター` → `konpyuutaa`) |
| `ん` + สระ | เติม `'` กันอ่านติด (`さんぜんえん` → `sanzen'en`) |
| `では` / `じゃ` | `dewa` / `ja` แยกเป็นคำ |

บรรทัดที่มี **คันจิอยู่นอกวงเล็บ** หรือมี **อักษรไทยปน** จะไม่ใส่คำอ่าน
(อ่านแทนให้ครบไม่ได้ ใส่ไปครึ่ง ๆ กลาง ๆ จะหลอกตามากกว่า)
ส่วนคันจิที่อยู่ในวงเล็บกำกับ เช่น `せんせい (先生)` จะถูกตัดออกจากบรรทัดคำอ่าน เหลือ `sensei`

ถ้าบรรทัดไหนอ่านผิด กำหนดทับได้ด้วย `romajiFix` ใน pack

```js
romajiFix: { 'パワー電気': 'pawaa denki' }
```

หัวข้อในโหมดอ่านสรุปใส่ `table: { head: [], rows: [[]] }` ได้ ถ้าข้อมูลต้องเรียงเป็นคอลัมน์
(เช่น ตารางตัวเลขญี่ปุ่น ซึ่งจัดด้วย `code` ให้ตรงคอลัมน์ไม่ได้)

### ท่องศัพท์ (vocab)

pack ที่มี `vocab: [...]` จะได้ 3 โหมดศัพท์เพิ่มให้เอง (ท่องศัพท์ · ฝึกจำศัพท์ · จำลองสอบศัพท์)
ตัวอย่างจริงอยู่ที่ `content/jpn5-vocab.js`

```js
vocab: [
  { id: 'l1v07', ch: 1, page: 48, group: 'อาชีพ', pic: '👨‍🏫', kana: 'せんせい', kanji: '先生', th: 'คุณครู, อาจารย์' },
  { id: 'l1v27', ch: 1, page: 49, group: 'ประเทศ', flag: 'th', kana: 'タイ', th: 'ไทย' }
]
```

| field | ความหมาย |
|---|---|
| `id` | ต้องไม่ซ้ำใน pack — ใช้เก็บความจำ Leitner **อย่าเปลี่ยนทีหลัง** ไม่งั้นคะแนนเดิมหาย |
| `ch` / `page` / `group` | บทที่ / หน้าในหนังสือ / หมวดย่อย — ใช้จัดกลุ่มและกรอง |
| `kana` | คำเขียนด้วยฮิรางานะ/คาตากานะ — **โรมาจิสร้างให้อัตโนมัติ** และตัวระบบติดป้าย ひらがな / カタカナ ให้เอง |
| `kanji` | คันจิ (ไม่ใส่ก็ได้) โชว์ตัวเล็กเป็นของแถม · ตอบเป็นคันจิในโหมดสอบก็นับว่าถูก |
| `th` | ความหมายภาษาไทย |
| `pic` | รูปแบบอีโมจิ: `'🙋'` · ซ้อนหลายตัว `['👉','📍']` · ตัวอักษรล้วน `'1,000'` |
| `flag` | ธงชาติ SVG ในตัว (ไม่ต้องต่อเน็ต): `th us uk in id kr cn de jp br it ch fr` — ใช้แทน `pic` |
| `alt` | รูปสุภาพ/คำที่ใช้แทนกันได้ (เช่น `おいくつ`) — ตรวจเป็นคำตอบที่ถูกด้วย |
| `note` | จุดที่ต้องระวัง (โชว์ในโหมดท่อง/ฝึก แต่**ไม่โชว์ในกระดาษข้อสอบ** กันหลุดเฉลย) |
| `exam: false` | ไม่เอาไปสุ่มในโหมดจำลองสอบ (เช่น ชื่อบริษัทสมมุติ) |

ใน `kana` เขียน `[お]みやげ` = ใส่หรือไม่ใส่ `お` ก็ถูก · `～さん` = ตอนตรวจไม่นับ `～`

**โหมดจำลองสอบ** ตรวจเข้มแบบข้อสอบจริง — ต้องพิมพ์เป็นตัวญี่ปุ่น และต้องถูกชนิดตัวอักษร
(พิมพ์ `あめりか` แทน `アメリカ` ไม่ผ่าน · พิมพ์โรมาจิไม่ผ่าน แต่ระบบจะบอกว่าคำถูก)
รูปประกอบซ่อนไว้ กด 💡 ถ้าอยากได้คำใบ้ · ปุ่ม 🔊 ในการ์ดใช้เสียงอ่านของเบราว์เซอร์ (ต้องมีเสียงภาษาญี่ปุ่นในเครื่อง)

> รูปเป็นอีโมจิ เพราะไม่ต้องดาวน์โหลดไฟล์ภาพและยังเปิดออฟไลน์ได้ · แนะนำใช้อีโมจิเวอร์ชันเก่า ๆ
> เพื่อให้ Windows 10 แสดงผลได้ (ตัวที่ใหม่กว่า Emoji 12 อาจขึ้นเป็นกล่องว่าง)
